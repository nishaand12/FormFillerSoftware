Installation Instructions

Windows Installation Steps

  1. Download the Windows Portable ZIP file
  2. Extract the ZIP file to a location like:
    • C:\Program Files\PhysioClinicAssistant\
    • Or your Desktop or Documents folder
  3. Open the extracted folder
  4. Double-click PhysioClinicAssistant.exe to run
  5. Log in with your account credentials
  6. Wait for AI models to download on first run (~4.3GB, 10-15 minutes)

First Run Note

The app will automatically download AI models (~4.3GB) on first launch. This ensures you always have the latest models and keeps the download small. Make sure you have a stable internet connection for the initial setup.

macOS Installation Steps

  1. Download the macOS installer (.dmg file)
  2. Double-click the downloaded file to mount the disk image
  3. Drag the PhysioClinic Assistant to your Applications folder
  4. Run the app from Applications
  5. Follow the setup wizard to configure your system
  6. Wait for AI models to download on first run (~4.3GB)

Beta Build Security Bypass

Important: Beta Release Notice

This is a beta release that is not yet code-signed. Your operating system will show security warnings because the app isn't signed with an approved certificate. This is normal for beta software and does NOT mean the software is malicious.

Bypassing Windows SmartScreen

When you first run the app, Windows SmartScreen may block it with a message like "Windows protected your PC".

Method 1: Click "More info" (Easiest)

  1. When you see "Windows protected your PC", click "More info"
  2. Click "Run anyway"
  3. The app will now run normally

Method 2: Unblock the ZIP File (Before Extracting)

  1. Right-click the downloaded ZIP file
  2. Click Properties
  3. At the bottom, check the box next to "Unblock"
  4. Click OK
  5. Now extract and run the app normally

Method 3: PowerShell Command (Advanced)

Open PowerShell as Administrator and run:

# Navigate to where you extracted the app cd "C:\Path\To\PhysioClinicAssistant" # Unblock all files recursively Get-ChildItem -Recurse | Unblock-File

Why This Happens

Windows SmartScreen blocks applications that don't have a code signing certificate from a trusted Certificate Authority. Code signing certificates cost $200-500/year. Once we obtain a certificate for the production release, these warnings will no longer appear.

Bypassing macOS Gatekeeper

After downloading, you may see a "damaged" error or "cannot be opened because the developer cannot be verified". The file is fine!

Method 1: Terminal Command (Recommended)

Open Terminal (Applications -> Utilities -> Terminal) and paste:

xattr -cr ~/Downloads/PhysioClinicAssistant-*.dmg

Press Enter. Now open the DMG file normally!

After dragging the app to Applications, also run:

xattr -cr /Applications/PhysioClinicAssistant.app

Then right-click the application and click Open.

Method 2: Right-Click Method

  1. Right-click the DMG file (or the app after installation)
  2. Click "Open"
  3. Click "Open" again in the dialog

If you still see "damaged", use the Terminal command instead.

Method 3: Transfer Without Quarantine

To avoid this entirely, transfer the file via:

  • AirDrop (Mac to Mac)
  • USB drive
  • Local network sharing

Files transferred these ways don't get the quarantine flag!

Why This Happens

macOS Gatekeeper blocks unsigned apps downloaded from the internet. The xattr command removes the quarantine flag. This is safe - just make sure you trust the source! Production builds will be signed by Apple and won't need this.

Uninstall & Data Cleaning

Uninstalling on Windows

Step 1: Remove the Application

Since this is a portable app, simply delete the folder where you extracted it:

  • Navigate to where you extracted PhysioClinicAssistant
  • Delete the entire folder

Step 2: Remove Application Data (Optional)

To remove all saved data, settings, and downloaded models:

  1. Press Win + R to open Run dialog
  2. Type %APPDATA% and press Enter
  3. Delete the folder: PhysioClinicAssistant
  4. Press Win + R again
  5. Type %LOCALAPPDATA% and press Enter
  6. Delete the folder: PhysioClinicAssistant (if present)

Warning: Data Locations

The following data will be removed when cleaning:

  • %APPDATA%\PhysioClinicAssistant\ - Settings, database, AI models (~4.3GB)
  • %LOCALAPPDATA%\PhysioClinicAssistant\ - Logs and cache

This includes all patient data, transcripts, and filled forms. Make sure to backup any important files first!

PowerShell: Complete Cleanup (Advanced)

To remove all data at once, open PowerShell and run:

# Remove application data Remove-Item -Recurse -Force "$env:APPDATA\PhysioClinicAssistant" -ErrorAction SilentlyContinue # Remove local app data (logs, cache) Remove-Item -Recurse -Force "$env:LOCALAPPDATA\PhysioClinicAssistant" -ErrorAction SilentlyContinue # Remove temp files Remove-Item -Recurse -Force "$env:TEMP\PhysioClinicAssistant" -ErrorAction SilentlyContinue Write-Host "Cleanup complete!" -ForegroundColor Green

Uninstalling on macOS

Step 1: Remove the Application

  1. Open Finder
  2. Go to Applications
  3. Drag PhysioClinicAssistant.app to the Trash
  4. Empty the Trash

Step 2: Remove Application Data (Optional)

To remove all saved data, settings, and downloaded models:

  1. Open Finder
  2. Press Cmd + Shift + G (Go to Folder)
  3. Enter: ~/Library/Application Support/
  4. Delete the folder: PhysioClinicAssistant

Also remove logs:

  1. Press Cmd + Shift + G again
  2. Enter: ~/Library/Logs/
  3. Delete: PhysioClinicAssistant folder (if present)

Warning: Data Locations

The following data will be removed when cleaning:

  • ~/Library/Application Support/PhysioClinicAssistant/ - Settings, database, AI models (~4.3GB)
  • ~/Library/Logs/PhysioClinicAssistant/ - Application logs

This includes all patient data, transcripts, and filled forms. Make sure to backup any important files first!

Terminal: Complete Cleanup (Advanced)

To remove all data at once, open Terminal and run:

# Remove the application rm -rf /Applications/PhysioClinicAssistant.app # Remove application data (settings, database, models) rm -rf ~/Library/Application\ Support/PhysioClinicAssistant # Remove logs rm -rf ~/Library/Logs/PhysioClinicAssistant # Remove cache rm -rf ~/Library/Caches/PhysioClinicAssistant echo "Cleanup complete!"
